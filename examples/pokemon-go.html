Example notes

A reusable workflow playground

This fictional Pokémon Go outing demonstrates connected views, editable cards, decision branches, and portable saves. Replace the seed JSON to map another workflow.

What saves

Dragging and editing update the workspace model. Browser storage remembers it locally; HTML and JSON exports preserve a portable copy. No server or game account is connected.

Customize

Change board titles, nodes, and labeled connections in the seed JSON. Keep stable IDs and valid endpoints. Use the inspector to edit summaries, notes, and links.

Unofficial fan-made planning example. Pokémon Go and related names belong to their respective owners. No official art, live event data, or gameplay automation is included.
